# Invoice Download in Customer Portal

## Background
Customers want to download their invoices from the portal. Currently they have to email finance, which is slow.

## Requirements
- Users can download invoices as PDF.
- Should also support Excel export.
- Download should be fast and user-friendly.
- Users should only see their own invoices.
- Show the last invoices on the dashboard.
- The invoice PDF is already generated by SAP and stored in SharePoint, so we just need to link to it.
- Finance will no longer need to handle invoice emails.

## Design
Add a new "Invoices" tab in the portal. Fetch invoices from SAP via the API and display them in a table with a download button. Use the existing login.
